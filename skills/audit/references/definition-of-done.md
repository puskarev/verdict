# Definition of Done для исправления

Постоянная планка: её проходит каждое исправление из фазы 6, независимо от того, насколько оно маленькое. Критерий готовности пункта (из отчёта) отвечает на вопрос «починили ли мы *это*». Definition of Done отвечает на вопрос «доведено ли до конца». Нужны оба.

## Каждый пункт

### Правильность
- [ ] Критерий готовности пункта из отчёта выполнен
- [ ] Проверено **в работе**, а не только «скомпилировалось»: запуск, запрос, тест, скриншот
- [ ] Для бага и `S`/`R`: проблема воспроизводилась до правки и не воспроизводится после
- [ ] Если в проекте есть тесты: новый тест падает без правки и проходит с ней
- [ ] Существующие тесты, сборка, линтер и типы не стали хуже, чем были в базовом состоянии из фазы 1
- [ ] Обработаны пути ошибок, а не только удачный сценарий

### Для `P` (скорость)
- [ ] Есть числа «до → после» одним и тем же способом замера
- [ ] Улучшение заметно, а не на уровне погрешности. Если нет — откати правку и запиши, что не помогло

### Качество
- [ ] Правка ограничена пунктом, без попутного рефакторинга
- [ ] Повторяет паттерн, принятый в проекте, а не вводит новый
- [ ] Нет отладочного вывода, закомментированного кода и мёртвых веток
- [ ] Нет дублирования бизнес-логики
- [ ] Абстракции оправданы: три похожие строки лучше преждевременного обобщения

### Интеграция
- [ ] Учтены миграции, конфиги и env: если нужна новая переменная, она добавлена в `.env.example` (без значения)
- [ ] Не сломана обратная совместимость публичного API, формата данных и deeplink'ов (или пользователь знает об этом и согласился)

### Документация и контекст
- [ ] Если изменились команды, структура или появился новый подводный камень, обновлены `docs/PROJECT_MAP.md` и CLAUDE.md
- [ ] Строка в таблице «Статус исправлений» отчёта обновлена: статус, файлы, проверка, коммит или «не закоммичено»

### Безопасность
- [ ] Новый код не пишет в логи секреты и персональные данные
- [ ] Ввод из недоверенных источников (формы, вебхуки, сообщения боту, ответы ИИ) валидируется на сервере
- [ ] Ответ модели ИИ не попадает в `eval`, SQL, shell, `innerHTML` или пути к файлам

## Красные флаги

- «Готово, просто ещё не запускал»: непроверенная работа не готова.
- «Тесты прошли» вместо «готово», когда регрессии, документация или проверка в работе пропущены.
- Планка снижена «потому что маленькая правка».
- Пункт отмечен ✅ без записи, как он проверен.
